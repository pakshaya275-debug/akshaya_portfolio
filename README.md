# Akshaya P — Personal Portfolio

A minimal, premium portfolio website for Akshaya P, built as a lightweight static site.

## Structure

- `index.html` — complete portfolio
- `assets/resume/` — place the final resume PDF here
- `assets/certificates/` — place certificate PDFs here when ready

## Before publishing

1. Add your final resume as:
   `assets/resume/Akshaya_P_Resume.pdf`
2. Optionally add certificate files.
3. Review project descriptions and links.
4. Open `index.html` locally and test all links.
5. Deploy using GitHub Pages, Netlify or Vercel.

## Notes

The site intentionally avoids exaggerated claims and keeps the content easy to update as more projects, internships and achievements are added.
